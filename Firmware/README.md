This folder contains the firmware for the Freedom Voting Machine.

## Volunteering Needed

Right now this project is greenfield status. We are basing this firmware on mbed using the [ScriptTek API](https://github.com/KabukiStarship/ScriptTek). ScriptTek is useful for making hardware control surfaces with mbed and the [Serial Chinese Room, Interprocess, and Telemetry (SCRIPT) Protocol and SCRIPT Script (Script2)](https://github.com/KabukiStarship/Script2).
